# Changelog

## Lottie Optimiser 1.5.0 (unreleased)
- **Duplicators now export properly**, each copy keeping its own position and delay.
- **Shader image fill support**.
- **Fill transparency support** 
- **Visibility support**
- **Exports no longer start on the wrong colour or frame** when Playback Range is trimmed.
- **Layer and duplicator level opacity support**
- Helper nodes such as falloffs **no longer leak into the export.** 
- **Linked images save into their own folder when embedding is disabled.**
- **Cull all invisible layers.**
- **Anything repeated is stored once**: shared artwork, colour animations, blinks and duplicator animations collapse to one copy each, keeping their own timing.
- **Optimised exports come out less than half the size**, with no visible difference from the original.

## Lottie Optimiser 1.3.0 (2026-10-08)
- Optimisation improvements
- UI updates

## Lottie Optimiser 1.2.0 (2026-10-08)
- Added support for **Tapered Strokes**, **Auto-Animate deformer** and **Shader Arrays**
- Improved fidelity of gradients and added gradient stroke support
- Updated UI
